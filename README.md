[访问博客](https://jxtzz.github.io/)

## 本地预览

基于 [Material for MkDocs](https://github.com/squidfunk/mkdocs-material)。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m mkdocs serve
```

## 内容目录

- `docs/papers/`：论文阅读
- `docs/translations/`：课程翻译
- `docs/deep-learning/`：理论基础
- `docs/engineering/`：工程实践
- `docs/journal/`：学习记录
