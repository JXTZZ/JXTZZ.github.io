# 计算机视觉学习路线：先打基础，再选方向

我现在更关心的不是把所有 CV 模型都学一遍，而是尽快判断自己愿意在哪类问题上长期投入。下面这份路线把共同基础和研究分支分开：前半段练所有方向都需要的能力，后半段用小项目试方向。

## 1. 先建立一张地图

|方向|模型在回答什么|常见输出|适合的兴趣|
|---|---|---|---|
|图像分类与表征学习|图里是什么，怎样得到可迁移特征|类别、embedding|喜欢模型结构、自监督学习、数据问题|
|目标检测与分割|对象在哪里，像素属于谁|框、mask、关键点|喜欢明确任务和工程落地|
|三维视觉|相机和物体在三维空间中的关系是什么|深度、位姿、点云、网格|喜欢几何、机器人、AR/VR|
|视频理解|发生了什么，运动如何随时间变化|动作、轨迹、时序片段|喜欢动态场景、行为理解|
|视觉语言|图像与文本如何对齐和推理|检索、描述、问答、grounding|喜欢多模态和大模型|
|生成式视觉|怎样生成或编辑符合条件的图像/视频|图像、视频、3D 内容|喜欢概率模型、创作工具|
|具身视觉|视觉信息怎样变成动作|物体状态、轨迹、控制动作|喜欢机器人和闭环系统|
|垂直领域视觉|怎样在特定数据和约束下可靠工作|检测、测量、异常判断|喜欢医疗、遥感、工业等具体场景|

R-CNN、FCN、YOLO、ViT、Diffusion 并不是互斥方向，它们是不同年代形成的模型和任务范式。选方向时先看问题、数据和评价方式，再决定需要补哪类模型。

## 2. 所有方向共用的基础

### 2.1 数学与深度学习

这部分不用一次学完，做到能跟着代码解释张量如何变化即可。

- 线性代数：向量空间、矩阵乘法、特征值/SVD、坐标变换；
- 微积分与优化：链式法则、梯度下降、学习率、正则化；
- 概率统计：最大似然、交叉熵、条件概率、期望与方差；
- 网络组件：CNN、normalization、residual、attention、MLP；
- 训练诊断：过拟合、类别不平衡、数据泄漏、梯度异常。

仓库里的[线性回归](Linear_Regression.md)、[Softmax 回归](Softmax_Regression.md)、[MLP](MLP.md)、[计算图](Computational_Graph.md)和[注意力机制](attention.md)可以作为第一遍入口。

### 2.2 图像处理与相机几何

只会调模型很难处理真实视觉系统。至少应能解释：

- RGB、HSV、灰度、动态范围和归一化；
- resize、crop、插值、卷积、频域的基本含义；
- 相机内参、外参、畸变和针孔模型；
- 齐次坐标、单应性、极线约束、三角测量；
- 数据增强是否改变标签，例如旋转对重力方向任务可能并不合理。

建议用 OpenCV 做一个相机标定小实验，再用两张图完成特征匹配和基础矩阵估计。它比只背公式更容易暴露坐标系混乱的问题。

### 2.3 工程能力

- 熟悉 PyTorch 的 `Dataset`、`DataLoader`、自动混合精度和 checkpoint；
- 会记录配置、随机种子、训练曲线和评测脚本；
- 能读懂 CUDA OOM，区分参数、梯度、优化器状态和 activation 的显存；
- 先复现小模型和小数据集，再扩大分辨率与 batch size；
- 评测时保留失败样例，不只看一个平均指标。

## 3. 第一阶段：用经典任务补齐 2D 基础

### 3.1 图像分类

学习顺序：`LeNet/AlexNet → ResNet → ViT → 自监督表征`。

要弄明白的不是模型年份，而是几次表示变化：卷积如何利用局部性，残差为何让深层网络更容易优化，ViT 如何把图像切成 patch，自监督模型如何在没有人工类别标签时学习特征。

练习：

1. 在 CIFAR-10 上训练一个小型 ResNet；
2. 画出 train/validation loss，主动制造一次过拟合再修正；
3. 冻结预训练 backbone，只训练 linear probe；
4. 比较从头训练、监督预训练特征和自监督特征。

可以把 [DINOv2](https://arxiv.org/abs/2304.07193) 当作现代视觉表征的阅读入口。第一遍只看训练目标、数据构造和下游评测，不必马上复现大规模预训练。

### 3.2 目标检测

学习顺序：`R-CNN/Faster R-CNN → YOLO → DETR`。

这一条线能看清两种思路：先产生候选区域再分类回归，以及把检测改写为集合预测。需要掌握 IoU、NMS、anchor、Hungarian matching、mAP 和小目标误差分析。

练习：选一个小型自建数据集，用成熟框架训练检测器。重点记录标注规范、类别分布和错误类型。若只盯着 mAP，很容易漏掉重复框、漏检小物体和背景误检之间的区别。

### 3.3 语义、实例与全景分割

学习顺序：`FCN/U-Net → Mask R-CNN → promptable segmentation`。

- semantic segmentation 给每个像素分类；
- instance segmentation 还要区分同类的不同实例；
- panoptic segmentation 同时处理 things 与 stuff；
- promptable segmentation 根据点、框、mask 或时序提示返回目标区域。

[SAM 2](https://arxiv.org/abs/2408.00714) 把可提示分割扩展到了图像和视频。适合做一个交互式标注或视频物体跟踪工具，用实际交互次数、速度和遮挡后的恢复能力评估，而不是只展示几张成功截图。

## 4. 第二阶段：用短项目试方向

每条支线用 2～3 周，做出一个能运行、能评测、能解释失败原因的小项目。完成两个支线后再决定主方向，比一开始按论文热度选题可靠。

### A. 三维视觉：和具身智能最直接相连

知识点：

- 深度估计、双目与多视图几何；
- camera pose、PnP、bundle adjustment、SLAM；
- 点云、voxel、mesh、implicit representation；
- 6D object pose、三维检测、tracking；
- NeRF、Gaussian Splatting 与新视角合成。

项目建议：

1. 用手机拍一组多视角图像，恢复相机轨迹和稀疏点云；
2. 用 RGB-D 数据完成物体点云分割和 6D pose 可视化；
3. 给同一物体做遮挡前后的位姿跟踪，记录漂移和失败条件。

[VGGT](https://arxiv.org/abs/2503.11651) 把相机参数、深度、point map 和 point track 放进统一的前馈模型，适合用来观察“传统几何模块”与“预训练几何模型”正在怎样结合。但相机模型、坐标变换和误差指标仍要会算，否则只能把它当黑盒。

### B. 视频理解：把单帧观察扩展到事件和轨迹

知识点：光流、tracking、action recognition、temporal localization、video segmentation、长期依赖。

项目建议：

- 对一段操作视频做目标分割与轨迹可视化；
- 比较单帧分类器和短视频模型在动作识别上的差异；
- 人为加入遮挡、镜头移动和长时间静止，分析跟踪器何时丢失目标。

如果对 SPOT 里的人类演示、关键帧和物体轨迹更感兴趣，这条支线应和三维视觉一起学。

### C. 视觉语言：关注语义对齐与 grounding

知识点：contrastive learning、image-text pretraining、cross-attention、captioning、VQA、referring expression、open-vocabulary detection。

项目建议：

- 用 CLIP 类特征做 zero-shot 分类和图文检索；
- 收集一组容易混淆的描述，分析模型靠对象、属性还是背景匹配；
- 将文本指定的对象 grounding 到框或 mask，而不只生成自然语言回答。

这条路线和具身智能的交点是：语言负责指定任务，视觉负责把词落到场景中的对象与关系上。

### D. 生成式视觉：学习分布，不只学习标签

知识点：VAE、GAN、diffusion/flow matching、条件生成、image/video editing、生成评测。

项目建议：

- 在小数据集上训练一个 diffusion model，完整写出加噪和去噪过程；
- 做带 mask 的局部编辑，分别评估文本一致性和未编辑区域保持；
- 对比像素指标、感知指标和人工偏好，理解“生成得像”为什么难以用单一数值概括。

算力不足时不必训练大模型，可以研究采样、条件控制、LoRA 或评测。

### E. 具身视觉：让感知进入闭环

视觉在机器人里不是独立的识别模块。状态估计误差会继续传到规划和控制，动作又会改变下一帧观察。

需要补的内容：

- object-centric representation、6D pose 与 affordance；
- imitation learning、behavior cloning、diffusion policy；
- calibration、hand-eye coordination、visual servoing；
- sim-to-real、domain shift、失败恢复和不确定性；
- VLM/VLA 如何把语言与连续动作连接起来。

项目建议：

1. 在仿真中完成“检测/分割 → 位姿或目标点 → 控制”的闭环；
2. 给观察加入遮挡或位姿噪声，画出成功率随感知误差的变化；
3. 复现一个小型行为克隆任务，再替换视觉 backbone 比较迁移效果。

[OpenVLA](https://arxiv.org/abs/2406.09246) 可以作为 VLA 的系统入口。阅读时把视觉编码器、语言模型、动作表示、机器人数据和微调方式分别列出来，不要把整套系统笼统记成“多模态大模型”。

## 5. 结合当前笔记，我更建议的主线

从仓库里 ALOHA、DP3、OpenVLA、SPOT 等阅读记录看，最连贯的一条路线是：

```text
2D recognition / segmentation
        ↓
相机几何 + depth + point cloud
        ↓
object pose / tracking / 3D representation
        ↓
video demonstration + object trajectory
        ↓
imitation learning / VLA / closed-loop manipulation
```

这条线的优点是，已有论文阅读能直接转成实验问题。比如 SPOT 中最值得复现的未必是整个扩散策略，可以先测位姿跟踪在遮挡、对称物体和相机变化下的误差，再研究这些误差怎样影响轨迹执行。

备选主线是“视觉语言 + grounding”。它与 VLA 同样相关，硬件门槛更低，但要避免只做问答 demo；最好把输出落到 box、mask、point 或可执行子目标上。

## 6. 一个 12 周的试跑计划

|周数|内容|交付物|
|---|---|---|
|1～2|CNN、ResNet、训练诊断|CIFAR-10 实验报告，含错误样例|
|3～4|检测或分割|自建小数据集、训练脚本和可视化|
|5|相机标定与多视图几何|标定参数、重投影误差、点云|
|6～7|深度/点云/6D pose|RGB-D 小项目，记录坐标系与误差|
|8|目标跟踪或视频分割|一段操作视频的轨迹和失败分析|
|9～10|复现一篇与主线相关的开源工作|可重复运行的配置和结果表|
|11|加入一个受控改动|消融：噪声、backbone、输入表示等|
|12|整理方向判断|两页总结：想继续的问题、证据、资源缺口|

项目报告固定回答五个问题：任务输入输出是什么，baseline 是什么，指标为什么适合，模型在哪些样例上失败，下一次实验只改哪个变量。这样做完 12 周后，留下的不只是一批跑通的 notebook，也能看出自己更喜欢几何、表征、生成还是系统。

## 7. 选方向时看这几个信号

|如果你更享受……|优先试的方向|
|---|---|
|推坐标变换、画几何关系、排查标定误差|三维视觉、SLAM、机器人视觉|
|设计损失、研究预训练特征为何迁移|表征学习、自监督学习|
|做标注工具、处理长尾和部署速度|检测、分割、工业视觉|
|理解事件、运动和长期依赖|视频理解、tracking|
|把语言落到对象和区域|视觉语言、grounding|
|研究采样、编辑与感知质量|生成式视觉|
|把感知、策略和控制连起来|具身视觉、机器人学习|

最后用现实条件做一次筛选：能拿到什么数据，有多少算力，是否有机器人或仿真环境，导师与同伴在哪些问题上能提供反馈。方向名称很大，真正可做的研究通常始于一个窄问题，例如“对称物体的 6D pose 不确定性如何影响操作”，而不是“我要做 3D CV”。
