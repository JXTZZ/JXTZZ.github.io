# 2026.8.31–2026.9.4 学习记录

## 核心阅读论文

### 一、ALOHA Unleashed

#### 概括

这篇文章主要研究：**模仿学习能否进一步扩展到复杂的灵巧机器人操作任务**。

过去 imitation learning 更多应用于 pick-and-place、pushing 等相对简单的操作，而本文提出通过：

> **大规模、多样化的 demonstration 数据 + expressive Diffusion Policy**

使低成本双臂机器人也能够完成挂衣服、系鞋带、精密插入等 **dexterous、long-horizon、bimanual manipulation** 任务。

模型输入为 **4 路 RGB 图像 + robot proprioception（机器人自身状态）**。RGB 图像分别通过 ResNet50 提取视觉特征，proprioception 通过 MLP 投影，最终形成 **1201 个 512 维 embedding** 输入 Transformer Encoder，得到当前环境的 latent representation。

动作生成部分采用 **Diffusion Policy + Action Chunking**：一次生成一个包含 **50 个 actions** 的 action chunk，对应约未来 1 秒的动作。推理时从 Gaussian Noise 初始化动作序列，Transformer Decoder 通过 Cross Attention 获取 Encoder 中的环境信息，并经过多次 diffusion denoising 逐步生成合理的动作轨迹。

#### 注意点

**1、Action Chunk 与 Open-loop**

模型一次生成一个包含 50 个 actions 的 action chunk。这个 chunk 在约 1 秒内 **open-loop 执行**，即执行过程中不会重新根据视觉修改当前 chunk。

但是一个 chunk 执行完成后，会重新获取：

> 4 路最新 RGB + 最新 proprioception

再生成下一个 action chunk。

因此更准确地说是：

> **chunk 内 open-loop，整体采用 receding-horizon control。**

**2、数据质量并不是越“完美”越好**

高质量 demonstration 很重要，但包含失败、retry 和 recovery 的轨迹同样有价值，因为能够教机器人：

> **任务出错以后应该如何恢复。**

因此数据需要在 **数量、质量和行为多样性**之间取得平衡。

**3、Diffusion Policy 与 L1 Regression**

L1 regression 在同一种状态存在多种正确操作路径时，可能倾向于学习不同路径之间的“平均动作”，而这个平均动作实际可能并不合理。

Diffusion Policy 更适合建模 **multimodal action distribution**，即：

> 同一种状态下可能存在多种合理操作方式。

在 ShirtMessy 中：

- Diffusion Policy：70%
- ACT-like L1 Regression：25%

但 Diffusion 并不是所有情况下都优于 ACT。例如低数据量的 DoubleInsertion 中 ACT 表现反而更好，因此可以理解为：

> **低数据、较简单任务中 ACT 比较容易训练；数据量大且行为多样时 Diffusion 的优势更加明显。**

**4、泛化能力存在明显的数据边界**

模型能够泛化到 unseen shirt、unseen ALOHA robot 和不同建筑背景，但对于训练数据中几乎没有出现的状态，例如：

- shirt face-down
- shirt 旋转 180°
- 鞋翻倒
- 鞋带严重缠绕

仍容易失败。

说明 imitation learning 的能力很大程度上仍受到 **training data distribution / dataset support** 的限制。

### 二、DP3：3D Diffusion Policy

#### 概括

DP3 的核心思想可以理解成：

> **把传统 Diffusion Policy 使用的 2D RGB 视觉输入，进一步升级成具有空间结构信息的 3D point cloud，并用一个轻量级 3D encoder 提取特征，再通过 Diffusion Policy 生成机器人动作。**

整体流程可以简化为：

```
RGB-D / 3D Observation
        ↓
Sparse Point Cloud
        ↓
3D Point Encoder
        ↓
Compact 3D Representation
        +
Robot State
        ↓
Diffusion Policy
        ↓
Action Chunk
```

其中 **Point Cloud（点云）** 可以理解成由许多三维空间中的点组成：

```
Point 1 → (x, y, z, ...)
Point 2 → (x, y, z, ...)
Point 3 → (x, y, z, ...)
...
```

这些点描述了物体、桌面、机器人等在真实三维空间中的位置和形状；根据视觉数据的设置，点还可以附带 RGB 等信息。

DP3 的关键出发点是：

> 对机器人 manipulation 来说，**物体在哪里、距离机械臂多远、空间结构是什么样**非常重要，而这些几何关系在 3D point cloud 中比单张 2D RGB 图像表达得更加直接。

作者没有使用非常庞大的 3D backbone，而是强调：

> **Sparse Point Cloud + Efficient Point Encoder**

即只保留较稀疏的点云，并通过较轻量的 point encoder 得到 compact 3D visual representation。

之后与 robot state 融合，再作为 Diffusion Policy 的条件，生成未来一段 action trajectory。

#### 与普通 Diffusion Policy 的区别

可以简单记成：

```
传统 Diffusion Policy：

2D RGB
 ↓
视觉 Encoder
 ↓
Diffusion
 ↓
Actions
```

DP3：

```
3D Point Cloud
 ↓
Point Encoder
 ↓
3D Spatial Feature
 ↓
Diffusion
 ↓
Actions
```

所以：

> **DP3 真正主要改的是 Observation Representation，而不是把 Diffusion 本身完全重新设计。**

#### 为什么 3D Representation 有优势

相比纯 RGB：

- 对物体深度和距离表达更直接；
- 空间几何关系更加明确；
- 对相机视角、背景变化等因素可能更加鲁棒；
- 特别适合 manipulation，因为机器人动作本身发生在 3D 空间。

因此 DP3 的核心 insight 可以总结成：

> **对于机器人操作任务，不一定需要非常复杂的视觉模型，一个 compact 的 3D representation 配合 Diffusion Policy 就可以获得很好的 manipulation performance。**

### 三、OpenVLA

#### 概括

OpenVLA 是一个开源的 **Vision-Language-Action Model（VLA）**，主要目标是构建一个能够根据：

> **视觉观测 + 自然语言指令**

直接输出机器人 action 的通用机器人策略模型。

整体可以理解为：

```
Image
 ↓
SigLIP + DINOv2
 ↓
视觉特征
       ↘
        LLM
       ↗
Language
 ↓
Action Tokens
```

视觉部分结合 **SigLIP 和 DINOv2**：

- SigLIP 更偏视觉-语言语义对齐；
- DINOv2 更擅长提取视觉空间和物体结构特征。

语言及主要 Transformer backbone 基于 **Llama 系列 7B 模型**。

最终机器人连续 action 会经过离散化，转换成可以由语言模型预测的 **action token**。典型控制 action 为 **7 维**，对应机械臂运动与 gripper 控制。

因此 OpenVLA 最大的特点是：

> **把机器人控制问题转换成类似 LLM 的 next-token prediction 问题。**

即：

```
Image + Language
        ↓
     Transformer
        ↓
预测 Action Token
```

#### 与 ALOHA Unleashed / DP3 的区别

这三篇论文其实正好代表三种不同侧重点：

|论文|输入表示重点|Action 建模|主要研究问题|
|---|---|---|---|
|**ALOHA Unleashed**|多视角 RGB|Diffusion|大规模数据能否学出高难度 dexterity|
|**DP3**|**3D Point Cloud**|Diffusion|3D 表示是否更适合 manipulation|
|**OpenVLA**|**Vision + Language**|Action Token|一个模型能否理解语言并完成多任务|

可以进一步概括成：

> **ALOHA Unleashed 关注“数据规模 + 灵巧性”；DP3 关注“3D perception”；OpenVLA 关注“通用 VLA 与多任务能力”。**

### 四、Octo
#### 概括
Octo跟OpenVLA比较相似，不同的是OpenVLA输出的是action tokens，Octo输出的是action chunk，目标也是输出一个通用的VLA模型，经过少量样本的微调，能够泛化到各种任务中。模型基本没有什么新意，主要贡献就是提供一个开源、可微调的模型。
#### 注意点
1、对新任务的泛化能力一般，没有预训练的任务成功率只有百分之5左右
2、goal image比language的效果更好，原因可能是数据中goal image更多，且goal image能够提供更多信息。
