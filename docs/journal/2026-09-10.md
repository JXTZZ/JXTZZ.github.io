# 补充 python 堆相关知识

## 1. 基本概念

堆（Heap）是一种**完全二叉树**，主要用于快速获取当前最大值或最小值。

- **最小堆**：父节点 ≤ 子节点，堆顶是最小值

- **最大堆**：父节点 ≥ 子节点，堆顶是最大值


Python 中通常使用 `list` 存储堆，对于下标 `i`：

```python
parent = (i - 1) // 2
left = 2 * i + 1
right = 2 * i + 2
```

注意：**堆不是完全有序数组**，只能保证堆顶一定是最大值或最小值。

---

## 2. Python `heapq`

Python 使用：

```python
import heapq
```

传统 `heapq` 默认是**最小堆**。

最常用操作：

```python
# 普通数组转最小堆，O(n)
heapq.heapify(nums)

# 插入元素，O(log n)
heapq.heappush(heap, x)

# 删除并返回最小值，O(log n)
x = heapq.heappop(heap)

# 查看最小值，O(1)
x = heap[0]
```

另外两个组合操作：

```python
# 先 push，再弹出当前最小值
heapq.heappushpop(heap, x)

# 先弹出原来的最小值，再 push
heapq.heapreplace(heap, x)
```

区别：

```text
heappushpop：新元素也参与最小值比较
heapreplace：一定删除原来的堆顶
```

## 3. 最大堆与优先级

### 最大堆

最常见写法是**存负数**：

```python
heap = []

heapq.heappush(heap, -x)

maximum = -heapq.heappop(heap)
```

例如原本：

```text
8 > 5 > 2
```

取负之后：

```text
-8 < -5 < -2
```

因此最小堆的堆顶 `-8` 就对应原来的最大值 `8`。

Python 3.14+ 也提供：

```python
heapq.heapify_max()
heapq.heappush_max()
heapq.heappop_max()
```

但 LeetCode 中掌握取负数即可。

### 元组作为优先级

`heapq` 可以存：

```python
(priority, value)
```

Python 会优先比较第一个元素。

例如：

```python
heapq.heappush(heap, (distance, node))
```

所以：

```python
dist, node = heapq.heappop(heap)
```

得到的一定是当前 `distance` 最小的数据。

这在 Dijkstra、任务调度等问题中非常常见。

## 4. 最重要的 LeetCode 使用模式

### Top K / 第 K 大

找**第 K 大**时，通常维护：

```text
大小为 K 的最小堆
```

模板：

```python
heap = []

for x in nums:
    heapq.heappush(heap, x)

    if len(heap) > k:
        heapq.heappop(heap)

return heap[0]
```

原理：

```text
堆中始终保存当前最大的 K 个元素

heap[0]
=
这 K 个元素里最小的
=
整体第 K 大
```

复杂度：

```text
O(n log k)
```

因此记住：

```text
第 K 大 → K 个元素的小顶堆
第 K 小 → K 个元素的大顶堆
```

---

### 其他常见场景

堆特别适合：

```text
Top K
第 K 大 / 第 K 小
不断加入数据，同时查询最大/最小值
优先级队列
Dijkstra 最短路径
合并 K 个有序链表
数据流中位数
```

例如 Dijkstra：

```python
heap = [(0, start)]

while heap:
    dist, node = heapq.heappop(heap)

    for nxt, weight in graph[node]:
        new_dist = dist + weight
        heapq.heappush(heap, (new_dist, nxt))
```

合并 K 个有序链表时，堆中保存每个链表当前最小的节点，复杂度通常为：

```text
O(N log K)
```

## 5. 核心记忆

复杂度：

|操作|复杂度|
|---|--:|
|`heap[0]`|O(1)|
|`heappush()`|O(log n)|
|`heappop()`|O(log n)|
|`heapify()`|O(n)|
|Top K|O(n log k)|

三个最重要模板：

```python
# 最小堆
heapq.heappush(heap, x)
x = heapq.heappop(heap)
```

```python
# 最大堆
heapq.heappush(heap, -x)
x = -heapq.heappop(heap)
```

```python
# 优先级队列
heapq.heappush(heap, (priority, value))
priority, value = heapq.heappop(heap)
```

最后只需要记住一句话：

> **堆不是为了把所有数据排序，而是为了高效维护当前最大值、最小值或 Top K。**
